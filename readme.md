# Simple Pokedex

A web app that lists the first 150 Pokémon. Click a Pokémon’s name to view its sprite and details in a modal.

## Features

- Loads Pokémon from the PokéAPI
- Responsive, Bootstrap-styled interface
- View Pokémon image and height

## Usage

1. Open `index.html` in your browser.
2. Click any Pokémon name to see its details.
